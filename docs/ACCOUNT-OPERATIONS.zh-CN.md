# 账号、审计与业务设置

## 初始化和受控恢复

服务没有默认密码、自动创建的管理员或公开密码重置入口。负责该服务的人
在受控交互终端自行运行，并使用与服务完全一致的私有数据目录：

```sh
markitdown-web bootstrap-admin --data-dir /absolute/private/data
markitdown-web reset-password --data-dir /absolute/private/data
```

两种操作均隐藏输入并要求二次确认；密码不得通过参数、环境变量或脚本
传入。密码范围统一为 6–128 个字符（最多 512 UTF-8 bytes），允许中文，
建议长口令及密码管理器。旧 Argon2id 哈希继续可用。6 字符是产品最低规则，
不代表满足所有组织的安全标准。仍保留登录限速和慢哈希。

已有管理员（包括停用管理员）时不能重复初始化。恢复操作者须先通过
自己组织认可的身份核实流程确认账号持有人；工具无法代替这个判断。
重置会撤销该账号全部会话，保持账号原有启停状态。不得删除数据目录或
手改 SQLite 来找回账号，也不得将真实密码写进日志、聊天或截图。

## 管理操作合同

- 管理员只能管理账号和邀请，不能因此查看他人的文档
- 单次邀请有效期 1–168 小时；撤销不影响已注册账号
- 用户每日额度 1–1000 次，按 UTC 日重置；不因取消/删除返还已用次数
- 用户文件上限 1–20 MiB，实际还受部署上限与引擎限制约束
- 不能停用自己或最后一位有效管理员；停用撤销会话并阻止结果发布
- 正在停止的解析任务待进程真正退出后才释放槽位

管理员设置页仅可修改三项业务默认值，版本冲突返回 409，非法更改整体
拒绝，无部分保存。默认额度和文件上限只影响新注册账号；保留期只影响
新接受任务，已有 expires_at 不被重写。部署/隔离/引擎模型/并发硬边界
只读，不提供关闭安全保护的开关。

审计与成功变更在同一事务保存，拒绝操作也有有限记录：操作者、目标ID、
时间、动作、前后数值、结果与请求ID。禁止正文、密码、邀请码、会话令牌
和服务器路径进入审计。Web 查询仅管理员可读，分页最多 200 条；默认
界面显示最近 100 条。审计与删除/停用恢复记录独立于文件 24 小时保留期，
v1 不自动删减它们。运营者须另行制定备份和审计保存政策，不能把文件到期
宣传为所有副本或安全日志已擦除。
