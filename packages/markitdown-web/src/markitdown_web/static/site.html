MarkItDown 支持页面列出的七种格式，没有 2 页硬门槛。Docling 是可选实验能力，需 Linux 服务启用，仅接收整份 1–2 页、最大 10 MiB 的文字型 PDF；账户上限可能更低。两种引擎当前均关闭 OCR。

macOS / Windows 是客户端系统。它们不会改变服务器的引擎能力，也不代表 Docling 在本机原生运行。

BEFORE YOU START

一些常见问题。

安装后可以离线转换吗？

当前客户端需要连接 MarkItDown 服务，转换发生在服务器。服务不可用时可重试连接；已经接收入队的任务可在服务恢复后到历史中确认状态。

怎样获取账户？

向你的工作台管理员索取一次性邀请码，连接服务后在“邀请注册”中创建账户。没有默认管理员密码，网页也不提供管理员初始化。

文件会保留多久？

默认从接收入队起保留 24 小时，服务管理员可调整新任务时长。请以每个任务显示的到期时间为准并及时导出。删除不等于安全擦除，下载副本、备份与日志有各自的生命周期。

转换结果能直接用于正式资料吗？

请先对照原文核查关键数字、单位、表头、脚注和阅读顺序。空警告列表不保证内容完整。下载的 Markdown 仍是不可信内容，目标应用需要自己的安全渲染设置。

客户端支持哪些平台？

当前工程规划 macOS Apple Silicon 与 Windows x64。此页只有实际存在的构建才出现下载链接；Intel Mac 暂未提供。安装签名、目标系统使用验收和线上服务部署的状态分别记录，不混用。
